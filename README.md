# Meteoroid

Shoot asteroids, collect powerups, and survive as long as you can in this fast-paced arcade shooter.  
Choose from **3 unique ships**, each with different weapons, stats, and visuals.  
Originally built in **Scratch**, then ported to run anywhere.

---

## 🚀 Features

- Three playable ships with unique weapons and firing styles  
- Multiple asteroid types with different speeds and behaviors  
- Powerups that enhance fire rate, damage, or movement  
- Score tracking and difficulty scaling  
- Runs in any modern browser  
- Portable EXE version included  
- Installer version included  
- Scratch `.sb3` source file included

---

## 📦 Downloads

### **Portable Version**
Runs instantly without installation.

`Meteoroid_portable v1.3.zip`

### **Installer Version**
Installs Meteoroid like a normal Windows app.

`MeteoroidInstaller.exe`

### **Browser Version**
Open the HTML file in any browser:

`Meteoroid v1.3.html`

### **Scratch Source**
Original project file:

`Meteoroid 1.3.sb3`
